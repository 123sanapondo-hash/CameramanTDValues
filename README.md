# Бот значень Cameraman TD

Щодня о заданій годині постить у Telegram-канал зміни значень предметів (наприклад `Spider Tv: 8000 → 7900`).

## Налаштування
1. У Telegram напиши @BotFather → `/newbot` → отримай токен.
2. Додай бота в свій канал як **адміністратора** з правом публікувати повідомлення.
3. Встанови залежності:
   ```
   pip install -r requirements.txt
   ```
4. Скопіюй `.env.example` в `.env` і заповни `BOT_TOKEN`, `CHANNEL_ID`, `POST_TIME`.

## Запуск
- `python bot.py --dry-run` — перевірити, що парсинг працює (нічого не шле).
- `python bot.py --now` — зробити один пост одразу.
- `python bot.py` — запустити постійно. Перший запуск лише запам'ятовує поточні значення, перший пост із змінами буде наступного дня о `POST_TIME`.

## Усі 47 предметів
Без додаткових налаштувань сторінка віддає лише перші 18 (решта підвантажується кнопкою "Load more"). Щоб бачити всі:
```
pip install playwright && playwright install chromium
```
і постав `USE_PLAYWRIGHT=1` у `.env`.

## Хостинг
Щоб бот працював 24/7, запусти його на VPS/Railway/Render або як systemd-сервіс. Стан зберігається в `state.json`.
